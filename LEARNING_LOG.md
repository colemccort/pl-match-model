# Learning Log

What I learned each session, in my own words.

## 2026-11-11 — Phase 0: Setup
- Raw data stays untouched in data/raw/ and cleaning happens in code, so anyone can rerun the analysis from the source and get the same result (reproducibility).
- A virtual environment (.venv) is a private Python for this project; I run source .venv/bin/activate before working, and requirements.txt lets anyone rebuild it.
- Git: add stages changes, commit saves a labelled snapshot, push uploads to GitHub. .gitignore lists files Git should skip.
- I use GitHub's noreply email for commits so my real email isn't public.
